# Portfolio — Cléa Godfrin

Portfolio UX/UI de Cléa Godfrin : site statique (HTML / CSS / JS, sans framework) présentant ses études de cas.

## Études de cas

- **Flying Secoya** — plateforme SaaS d'éco-responsabilité audiovisuelle (`flying-secoya.html`)
- **Tricount** — étude UX Research (`tricount.html`)
- **AIMETAMARQUE** — Legal Design, visual novel interactif (`aimetamarque.html`)
- **CNP Assurances** — lutter contre la mal-assurance, compétition PULSE 2026 (`cnp.html`)

## Lancer en local

Ouvrir `index.html` dans un navigateur (aucune dépendance à installer).

## Structure

- `index.html` — page d'accueil
- `*.html` — pages d'études de cas
- `css/` — styles partagés (`styles.css`) et polices (`fonts.css`)
- `assets/` — images des projets
